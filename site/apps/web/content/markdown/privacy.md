# Privacy

This page describes what Cevolta's *website* collects. The Cevolta
*protocol* is a separate, non-custodial system that never takes custody
of anyone's funds; this page is only about the site you're reading right
now.

## Waitlist

When you submit an email on this site, it's stored, together with the
time you joined, in a single private object in Vercel Blob storage. It's
used only to email you when Cevolta opens on Testnet. It is not sold,
shared with third parties, or used for anything else. There's no
self-service way to remove it yet — ask via [Contact](https://cevolta.xyz/contact)
and it'll be removed by hand.

## Analytics

This site uses Vercel Analytics and Vercel Speed Insights to see page
views and page-load performance. Both are cookieless: they don't set
tracking cookies, don't use a persistent identifier, and don't know who
you are beyond the email you choose to submit to the waitlist. Data is
aggregated, not tied to an individual visitor.

## Access

Waitlist entries are readable only by whoever holds Cevolta's admin key,
an environment variable set outside this repository, not by anyone who
can view the site's source.
